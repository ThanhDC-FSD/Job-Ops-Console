### Trạng thái vá `_etl_and_cv_rewrite_flow`

Snapshot triển khai hiện tại cho nhánh tuning này:

- CV rewrite da co `retrieval + fallback heuristic` theo feature flag, nen khi retrieval loi/empty van quay ve duong cu
- Rerank da duoc gate bang confidence (`top_score`, `top_gap`) de tranh dot CPU tren may yeu
- Prompt budget da dua tren tokenizer that neu co (`tiktoken`/HF tokenizer), fallback ve estimate chars neu khong co backend
- Context-pack da co helper trong `CvRewriteService` va da duoc build offline sau ETL crawl khi `TUNING_ENABLE_CONTEXT_PACK=1`
- Persisted cache dung SQLite WAL cho `kv` + `context_pack`, uu tien tai su dung ket qua context select/context-pack
- CV artifact render tu `_materialize_generated_artifact_set` co fallback ve mot writer docx don gian neu python-docx/docx2pdf khong chay duoc, nen UI van co link DOCX duoi bat ky dieu kien nao.
- Benchmark harness `scripts/python/run_now_etl_cv_flow.py` da co baseline + patch loop + gate p95 + upsert marker
- Nightly prediction Q&A da co script rieng `scripts/python/predict_night.py`, dung backend local (`ollama` mac dinh, `llama_cpp` optional)
- Script `scripts/python/predict_night.py` se in `[PREDICT] skipped disabled_by_flag` va thoat voi return code `0` neu `TUNING_ENABLE_INTERVIEW_PREDICTION=0` va khong co `--force`
- Automation UI/manual action prediction nay gui day du args cho script (`--mode nightly`, `--job-id`, `--cv-path`, `--recent-days`, `--limit`, `--shutdown-when-completed`) va co the gui `run_at` len API de dat lich one-off pending run, nen operator co the dieu phoi run tu giao dien
- Automation scheduler da co them `pipeline_type=interview_prediction` de co the sua gio chay lai qua schedule data
- Automation scheduler nay co them `automation_schedule_overrides` de lưu lần sửa một-một cho occurrence kế tiếp, đồng thời giữ nguyên schedule series

Nhung gi van duoc bao toan:

## Performance Impact of This Documentation Update

Dot cap nhat nay co them logic runtime nho cho pause/resume automation run. Danh gia tac dong:

- user-facing latency: khong anh huong dang ke khi flags tuning OFF; khi flags ON, retrieval/context-pack/caps duoc thiet ke de giu online cost trong ngan sach CPU
- LLM call time: khong doi
- hot path execution time: them rat nho cho check pause flag, metrics logger, va load cache/context-pack; phan nang da day ra offline/nightly
- compute/file I-O: them thao tac file/SQLite nhe (flag, checkpoint, cache, prediction artifacts)

Tac dong hieu nang duoc cai thien o tang van hanh:

- giam rui ro lock SQLite keo dai do co pause an toan
- giu duoc trang thai run ro rang, resume tiep tu checkpoint
- tang observability khi co `pause_requested_at`, `pause_checkpoint_path`, `pause_status`
- giam prompt assembly cost online khi da co context-pack/cache
- tach prediction Q&A ra night-run, tranh chen vao CV rewrite hot path
- giảm chi phí nhận thức ở tab Automation vì operator chỉ nhìn một bảng schedule thay vì hai nguồn gần giống nhau
- tác động runtime của override là nhỏ: thêm một bảng SQLite nhẹ + one-off APScheduler job cho từng lần sửa đơn lẻ
- front-end render cost gan nhu khong doi: them wrapper `overflow-x:auto`, bat `table-layout: fixed`, va co nut action theo grid de giam stretch layout o man hinh hep
- Shutdown sau ETL gio duoc chot theo tung schedule (flag crawl_config), chi kich hoat auto shutdown khi flag bat va trigger tu scheduler
- them mot dropdown action nhe o frontend; chi them xu ly UI cuc nho, khong doi query backend, payload, hay scheduler behavior
- them mot manual action button cho interview Q&A; chi la UI trigger, khong them tai runtime khi khong su dung
- manual interview Q&A panel chi mount khi duoc toggle, nen giam clutter UI va tranh render input khong can thiet
- Automation tab reload now degrades gracefully when one data source fails, so a temporary SQLite lock does not blank schedules and runs together
- company-filter search rewrite reduces crawl volume when a single company is targeted, shrinking job card fetch and detail extraction time
