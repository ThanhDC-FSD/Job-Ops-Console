## Counting Rule

This inventory counts only features explicitly described in `10.1`.

- Top-level pages are counted separately.
- Learning Quiz subpages are counted separately.
- Automation blocks are counted separately.
- Inputs in `Interview Q&A` are counted as UI features because they are explicitly listed as current inputs.
- Operational notes are not counted as separate features unless they describe a visible UI block or action.
